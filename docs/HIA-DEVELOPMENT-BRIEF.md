1. **Partnerships** — Unlock infrastructure and local capability with host institutions  
2. **Technology** — Medical and digital tech for access, quality, monitoring, coordination

## 3. Audiences and primary CTAs

Every page = user question + clear next action.

| Audience | Journey goal |
|----------|--------------|
| Government / teaching hospitals / hosts | Model → operations → partnership conversation |
| Investors / financiers / development partners | Proof, governance, model → corporate contact |
| HMOs / employers / healthcare partners | Relevant platform or partnership enquiry |
| Healthcare professionals / talent | Leadership, impact, opportunities |
| Media | Accurate corporate info + media contact |
| Patients / caregivers | **Route to OncoClinics, Rencare, or POCCH**—not a generic corporate form |

### Primary CTAs

- **Partner With Us** — header + final sections (main corporate CTA)  
- **Explore Our Operations** — homepage  
- **Discuss an Oncology Partnership** — OncoClinics  
- **Discuss a Renal Care Partnership** — Rencare  
- **Visit the Hospital Website** — POCCH  
- **Read Our Insights** / **View All Issues** — thought leadership  
- **Contact the Relevant Care Platform** — patient routing  

### External platform sites

- OncoClinics Africa → https://oncoclinicsafrica.com/  
- Rencare Africa → https://www.rencareafrica.com/  
- POCCH → hospital website (confirm official URL with management)  

Platform links must be real anchors (mouse, touch, keyboard); no decorative overlays blocking clicks. Open in same tab unless approved otherwise.

## 7. Design and content rules

| Topic | Rule |
|-------|------|
| Colour | HIA indigo (primary); cyan **#00CFF3**; deep navy; white; platform accents only from master brand files |
| Motion | Calm confidence—avoid excessive animation and decorative effects |
| Photography | Prefer real HIA facilities/teams; no unrelated dental/cosmetic/generic hospital stock |
| Logos | Original vectors; never stretch low-res or put in inconsistent white boxes |
| English | British: *centres*, *specialist*, *organisation*, etc. |
| Alt text | Descriptive for meaningful; empty for decorative |
| Images | WebP/AVIF, responsive sizes, explicit width/height |

## 8. SEO, a11y, privacy, tech

- Unique title + meta per page; canonicals; XML sitemap; OG tags  
- Structured data: Organisation (home), Person/ProfilePage (leadership), Article (insights), BreadcrumbList  
- WCAG **2.2 AA**; one H1; labels; keyboard; focus; contrast; `prefers-reduced-motion`  
- Privacy + Cookie notices before analytics/forms  
- HTTPS, backups, RBAC CMS, client+server form validation, rate limiting, custom 404/500  
- Staging password-protected and noindexed until launch
